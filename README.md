# 星轨数值工作台 · 崩坏：星穹铁道 4.6

访问页面：[https://silvera0218.github.io/HSR-Calculator/](https://silvera0218.github.io/HSR-Calculator/)

Excel 工作簿可通过页面左侧的“下载 Excel 工作簿”获取。

## 功能

- 面板采用游戏角色页的星空、中央立绘、左侧分区和右侧属性布局；光锥页显示当前卡图，遗器页显示对应部位与套装图标，资源随静态站点一起发布。
- 四人面板计算：角色等级与突破、星魂技能加级、光锥与叠影、行迹、2–5 星遗器主词条、套装固定属性与显式条件增益。
- 角色与光锥分别按命途筛选，图鉴查询保留筛选及搜索条件。
- 12 种副词条的加减计数：按原始档位均值累计；非百分比累计值四舍五入，百分比保留精度。
- 技能默认基础满级，按实际星魂提升对应技能等级；显示基础等级、星魂加级及最终等级。
- 面板加成来源明细；条件加成绑定当前光锥、套装、行迹或已解锁星魂，支持开关与层数。
- 伤害拉表：直伤、持续伤害、初始击破、超击破、欢愉与真实伤害；支持攻击加成扫描和 CSV 导出。
- 固定循环：按行动值推进战技点、能量、韧性与敌方生命，查看逐步日志和队员贡献。
- 数据图鉴：108 个角色/强化形态、648 条星魂效果、170 张光锥、62 个套装、774 件装备。
- 32 条公式参考；Excel 提供对应公式库、成长库、养成材料库及复合计算表。
- lieflat 图表：F5 队员伤害贡献、F2 累计伤害、F12 击破前后比较，采用 Mono 灰阶与本地 Inter 字体。
- 方案保存与读取；计算在浏览器本地执行。

## 运行与部署

`docs/` 是独立静态站点。GitHub Pages 从 `main` 分支的 `/docs` 发布，提交后由 GitHub 自动更新。

本机预览：在 `docs` 目录执行 `python -m http.server 8766 --bind 127.0.0.1`，访问 `http://127.0.0.1:8766/`。请通过 HTTP 打开，数据使用 `fetch` 读取。

## 数据与资源

数据以 [StarRailRes 固定快照 dbe8cdf](https://github.com/Mar-7th/StarRailRes/tree/dbe8cdfcfb0bf657b9fe1cf92d5537f118ccb487) 为基础，配套版本文件标记为 4.6。图片的逐项来源见 `docs/asset-manifest.json`；字体来源与许可见 `docs/font-manifest.json` 及对应字体目录。游戏图片权利归其原权利人，代码与第三方资源分别保留来源。

## 计算范围

星魂技能加级自动计算。条件星魂、触发层数、队伍增益、分段攻击、追加攻击、召唤物和特殊资源通过显式增益、倍率与循环输入表达，效果全文可在图鉴核对。

固定循环采用单目标期望模型与通用战技点、能量和削韧规则；它用于比较明确输入条件下的配装、星魂与队伍。完整角色状态机、时效增益和队伍生存模拟未自动实现。治疗和护盾的执行计算在配套 Excel 中提供，页面公式目录保留相应规则。

## 验证

前端核心公式及副词条、技能、来源条件输入通过独立 SymPy 检查；控件事件覆盖加减、切星级和方案保存读取。Excel 32 张工作表没有公式错误缓存，24 个动作与 120 行战斗事件通过独立重算。基础速度与受治疗等专项用例通过内存修改输入核验。验证范围和最终文件哈希见 `validation/`。
