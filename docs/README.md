# 星轨数值工作台

推荐双击本目录的 `启动页面.cmd`，会自动选择本机或 bundled Python，并打开本地页面。

手动启动：在本目录执行 `python -m http.server 8766 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8766 。不要直接双击 HTML，因为数据通过 HTTP 读取。

本运行包已包含固定数据与本地资源，无需安装 Node.js 或重新下载图片。数据快照为 StarRailRes 的 `dbe8cdfcfb0bf657b9fe1cf92d5537f118ccb487`。

功能：四人独立面板方案；角色等级突破、光锥等级叠影、2–5 星主词条、12 种副词条加减计数、套装固定属性与行迹；角色与光锥独立命途筛选；直伤、持续伤害、初始击破、超击破、欢愉与真实伤害拉表；固定循环行动值与 SP、能量、生命和韧性日志；所有角色形态、技能、全部星魂、光锥叠影、套装与全部装备图鉴；32 条公式参考目录；本机方案保存、CSV 导出。

副词条每次添加按当前星级的成长档位等权平均；固定生命、攻击、防御与速度先按原始均值 × 条数累计，再对累计值四舍五入；百分比词条保留原始累计值。控件显示每档均值、原始累计值与实际计入面板值。计数随方案保存，切换稀有度会重算累计值。手动副词条与条件增益单独叠加，避免重复输入自动累计值。

技能默认采用基础满级模式，训练上限从关联技能行迹节点读取（通常普攻 6、战技/终结技/天赋 10）。星魂加级按源数据中的技能 ID 应用，页面同时展示基础训练等级、星魂加级和最终等级。可切换手动训练等级，输入按各技能基础训练上限限定。行迹默认开启，固定属性按角色等级与突破条件计入。面板来源表列出实际贡献；已选光锥、套装和行迹全文可展开核对。

“来源条件加成”可绑定当前光锥、套装件数、行迹或已解锁星魂。每行选择面板属性、填写每层加成与层数，再勾选已触发；输入默认关闭且增量为零。切换角色或装备、降低星魂、关闭行迹后，失配或未解锁的来源停止计入，记录保留供核对。条件加成独立计入来源明细，保存方案时一并保存。基础速度增量先加入角色基础速度再乘速度百分比；施放治疗加成和受治疗加成分别显示。

图表采用用户指定 lieflat-charts 的真实 Basics 模板：F5 队员伤害贡献、F2 累计行动值伤害、F12 击破前后比较。按当前输入实时生成，点击或聚焦后按 Enter 重播。来源与选型见 chart-selection.md。图表区统一 Mono；Inter 字体本地保存，出处见 font-manifest.json。

固定循环使用单目标期望模型。普通普攻 / 战技 / 终结技的通用能量、战技点和削韧规则自动运行。条件星魂、队伍增益、分段、追加、召唤物与特殊行动机制使用显式增益、倍率和循环输入。页面公式与范围中列明自动处理边界。

开发验证在原工作目录完成：20 项面板、伤害、日志累计与图表单位通过独立 SymPy 校验；副词条的 48 条均值及累计四舍五入规则、56 个点击/撤回/星级切换/方案读取用例的 896 个面板输出通过独立 SymPy 校验，包含 2.2 × 4 的用户示例。运行包不附作者维护脚本。

资源出处见 asset-manifest.json，每张图片保留固定原始 URL；前端运行不依赖外部图片服务。
